Quadcopter Drone Simulation

A fully simulated Arduino-based quadcopter system featuring PID stabilisation, real-time sensor fusion, and motor control logic. Designed to demonstrate control systems engineering through an interactive and visual environment.

Core Features

PID Control

Maintains stable flight by continuously correcting roll and pitch.

Sensor Fusion

Combines gyroscope and accelerometer data for accurate orientation.

Motor Mixing

Distributes control signals across four motors in real-time.

Simulation Ready

Runs entirely in-browser using Arduino simulation tools.

Engineering Vision

This project represents the intersection of embedded systems, control theory, and simulation. Built to explore real-world drone dynamics without hardware constraints, it reflects a strong foundation in robotics and system design.
