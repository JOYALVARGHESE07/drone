System Architecture

FLIGHT
SYSTEMS

01 / IMU
IMU Sensor Fusion
MPU-6050 gyroscope + accelerometer fused via complementary filter (α=0.98). Roll and pitch at 50 Hz on I2C addr 0x68 (A4/A5).
02 / PID
PID Stabiliser
Dual-axis PID with configurable Kp, Ki, Kd. Anti-windup integrator clamping ±400 µs. Runs every 20 ms for 50 Hz control authority.
03 / ESC
Motor Mixing
X-frame mixing on D9/D10/D11/D6. PWM 1000–2000 µs via Servo lib. CW/CCW alternation for yaw torque cancellation.
04 / ALT
Altitude Hold
HC-SR04 ultrasonic D2/D3. 5-sample median filter. 40 kHz burst, echo timer TOF. 4 m range, ±3 mm accuracy.
05 / LCD
I2C LCD Display
LiquidCrystal_I2C 16×2 at 0x27. Shows ARM, altitude, roll, pitch, throttle. 200 ms refresh to prevent I2C bus saturation.
06 / SAFETY
ARM / DISARM
D4 push-button, 50 ms debounce. Hard motor lock when disarmed. PID integral zeroed on arm event. D13 LED mirrors state.
07 / THR
Throttle Control
10 kΩ pot on A0 → 10-bit ADC → mapped 0–5V to 1000–2000 µs. 5% low deadband. Capped during PID saturation.
08 / COMMS
Serial Telemetry
9600-baud USB serial. Roll, pitch, altitude, throttle, 4 motor values every cycle. Human-readable + CSV-ready format.
09 / LOOP
Real-Time Loop
Deterministic 50 Hz via micros() delta. Sensor read → filter → PID → mix → write, sequenced within 20 ms at 16 MHz.
