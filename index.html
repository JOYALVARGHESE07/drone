System Features

HOME
SYSTEMS

Every subsystem engineered for a truly automated eco-friendly smart home.

01 / ENV
Temp & Humidity
XHT11 (DHT11-compatible) on D10 reads temperature and humidity. Values displayed live on I2C LCD. Fan activates automatically above 30°C.
02 / WATER
Auto Irrigation
Capacitive soil sensor on A2 triggers the 5V relay (D7) to activate the water pump when moisture falls below threshold. Stops automatically when moist.
03 / LIGHT
Smart Lighting
Photoresistor (LDR) on A1 enables auto-switching SK6812 RGB LED (D11). Illuminance reading shown on LCD. Smooth color transitions for ambience.
04 / PIR
Motion Detection
PIR passive infrared sensor on D3 detects intruders. Triggers passive buzzer (D9) alert tone and can activate RGB LED flash sequence for visual alarm.
05 / UV
Solar UV Sensing
KS6032 UV sensor on A6 reads solar ultraviolet index. Displays safe/moderate/high labels on LCD. Integrated solar panel demonstrates renewable energy input.
06 / LCD
LCD Dashboard
I2C LCD1602 at address 0x27 shows all sensor readings simultaneously: temp, humidity, illuminance, UV index. Refreshes every second via I2C bus.
07 / FAN
PWM Fan Control
Fan motor on D5 (PWM) ramps up based on temperature. Solar panel can power the fan demonstrating green energy integration. Speed proportional to heat.
08 / RELAY
5V Relay Module
Single-channel 5V relay (KS6062) on D7 controls the DC water pump independently from the logic rail. Allows safe switching of higher-current loads.
09 / KEYPAD
Five-Key Menu
Five AD Key module on A0 provides analog-voltage keypad input for navigating LCD menu modes, adjusting thresholds, and selecting display pages without extra wiring.
