About the Project

This drone simulation replicates real-world quadcopter physics using Arduino-based control logic. A PID controller continuously stabilizes roll and pitch, ensuring smooth and controlled flight.

Sensor data from the MPU-6050 and ultrasonic modules is processed in real time, enabling altitude tracking and dynamic balancing.

Core Features

PID Stabilization

Maintains balance using real-time control loops.

Sensor Fusion

Combines gyroscope and accelerometer data.

Motor Mixing

Distributes power across 4 ESC motors.

Live Simulation

Runs interactively inside the browser using Wokwi.
